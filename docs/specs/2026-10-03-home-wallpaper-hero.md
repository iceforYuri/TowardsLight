> v1 的教训:壁纸带写死 50svh → 上滚顶态身份组被压到视口 88% 高度、intro 被裁 57px、
> 卡片离开视口后仍可多滚 181px(overshoot)、hero 高 1.29 屏导致背景图过度放大;
> sticky+发光编排讨论过却未进规格。v2 从 main 重开分支,整体设计先行。

## 效果全貌(白话版,先读这章)

### 打开首页的那一刻

整张背景图**完整铺满屏幕**——图片永远恰好一屏大小、按屏幕比例缩放,
不会只显示局部放大版,也不会因为屏幕高矮变化而被拉得忽大忽小。

画面上大致分三层:

- **上部约三分之二**:壁纸上浮着状态胶囊("Writing·深度思考中…")、大标题、
  两行介绍文字,整体在"导航下方到卡片之间"居中,行距疏朗;
- **下部约三分之一**:主卡片从底部探出头来——露出头像、名字、个人简介;
- **屏幕底边**:简介下面那条分隔横线**正好压在屏幕底边上**,像书页的装订线,
  不多露一丝内容。横线上方还有一行打字机缓缓打出的小字
  (写作天数 · 篇数 · 字数 · 标签数),与卡片顶之间留着舒适的呼吸距离。

### 往下滚(看内容)——和现在这个网站完全一样

背景、标题、卡片**一体向上滚动**:标题文字向上滑走,卡片带着近期文章向上
盖住壁纸,壁纸随之滚出屏幕,正常阅读到底部页脚。
全程没有任何吸附、回弹、卡顿感,就是普通的网页滚动。

### 往上滚(看壁纸)——这次的灵魂

从默认位置**轻轻向上推一下**(行程约三分之一个屏幕高,一次小幅滚轮手势),会发生:

1. **图片纹丝不动**(冻结满屏);卡片连同那圈**羽化**顺着滚动向屏幕下方退去,
   图片下半部分被一点点揭开——展开感来自遮挡物离场,不是图在动;
2. 标题那组文字起初跟着往下移,但**中心一碰到屏幕正中央就停住**,不再移动;
3. 继续上滚,停住的文字开始**变亮**,并泛起一圈淡淡主题色(珊瑚红)的柔光,
   像在壁纸上发光;
4. 滚到顶时:卡片恰好完全退出屏幕底部,羽化恰好完全离场——
   眼前是一张**干净、无任何渐变的 100% 满屏壁纸**,文字在正中央微微发光,
   统计行小字落在屏幕底边上方一点的位置。

**滚到顶就停了,不可能再多滚**——因为那里就是页面顶部本身,不需要任何
"吸附"机制,也就不存在"怎么还能继续滑动"的问题。

### 从壁纸状态滚回来

完全反向:文字先暗回正常颜色、光晕褪去,然后随内容一起上移;卡片从屏幕底部
升回来,羽化跟着回来,横线重新压回屏幕底边。随时可以中途停住,没有强制归位。

### 几个始终成立的兜底

- **刷新 / 浏览器前进后退**:记住你上次读到的位置,不会强行拉回默认位;
- **没有配背景图**:页面就是主题纯色背景,居中、锁底、全部排版照常成立;
- **系统开了"减少动态效果"**:不打字、不发光,但居中、锁底、壁纸冻结都在
  (冻结是位置行为,不是动画);
- **手机端**:屏幕放不下完整编排,进入即是"满屏壁纸 + 居中文字 + 卡片在底缘
  探头"的画面,下滚正常看内容;sticky 与发光编排照常。

### 和现状(main)相比,变了的只有三件事

1. 背景图永远恰好一屏大小、不再被拉长放大;简介线之上冻结不动,之下随内容滚走;
2. 上滚多一个"满屏壁纸 + 文字居中发光"的可探索状态;
3. 统计行从胶囊样式变回无背景的纯文字。
导航、卡片、文章列表、链接、联系区、页脚、页面切换动画——**全部不动**。

## 术语(每条附白话)

- **壁纸层**:首页 hero 的背景图层,高度恰好一屏(100svh)。以简介线为界:
  线之上(上滚行程)冻结满屏不动;线之下(阅读区)随内容一体滚动。
  白话:看壁纸时它像钉死的桌布;看内容时它像普通背景一样跟着滚走。
- **简介线**:简介块下方、锁底时恰好压在视口底缘的那条横线。
  它是两种滚动行为的分界线:线之上 = 壁纸区(冻结),线之下 = 阅读区(随动)。
- **冻结**:壁纸层在壁纸区的位移补偿——滚动多少就反向补偿多少,图片相对视口
  静止;进入阅读区后补偿停在行程 L,图片恢复随文档滚动。纯位置行为,不是动画。
- **羽化幕布**:统计行和主卡片身下的"衬布"——顶部约 200px 是 透明→页面底色 的
  渐变(这就是"羽化"),往下是纯页面底色。白话:卡片不是硬邦邦地压在图上,
  而是从图里"浮现"出来;这块衬布跟着卡片走,卡片退场的它一起退场。
- **身份组**:状态胶囊 + 大标题 + tagline + intro 四件文字的统称。
- **行程 L**:从默认位置往上滚到顶的距离 ≈ 卡片"露头"部分的高度(桌面实测约
  221px,约三分之一个屏幕)。白话:上滚一下就到壁纸,不用滚很久。
- **锁底**:默认状态下,简介线恰好压在屏幕底边,误差不超过 1 像素。
- **三态统计行**:统计小字的三种存在方式——平时浮在卡片顶缘上方 24px 处;
  上滚看壁纸时落在屏幕底边上方 24px;往下阅读时自然滑出屏幕。三种形态都不带背景。
- **发光**:文字颜色微微提亮 + 一圈主题色柔光(text-shadow)。幅度克制,
  是"壁纸上题字"的微光,不是霓虹灯。

## 状态机

> 以下章节是实现细节,供开发核对;对外效果一律以《效果全貌》为准。

```text
S0 默认态(进入,scrollY = L)          S1 满屏壁纸态(scrollY = 0,页顶即停止位)
┌────────────────────┐              ┌────────────────────┐
│ 导航                │              │ 导航                │
│  壁纸(冻结满屏)     │              │  壁纸(冻结满屏)      │
│  身份组(可见区居中) │              │  身份组(视口正中,发光)│
│  统计行(图上纯文字) │              │  统计行(底边上 24px)  │
│ ┌─卡片─────────┐   │              │  (卡片顶恰齐视口底缘) │
│ │ 简介块        │   │              └────────────────────┘
│ │ 横线══视口底缘 │   │
└─┴──────────────┴───┘
```

- **壁纸区(scrollY ∈ [0, L])**:壁纸层冻结满屏;上滚时卡片+羽化下移离场,
  身份组先随文档下移、中心触及视口正中即钉住,随后提亮 + accent 微光晕渐入。
- **阅读区(scrollY > L)**:壁纸层解冻,与身份组、幕布、卡片一体随文档上移,
  页面与常规文档无异。
- 页顶(scrollY=0)即 S1,**物理上不存在 overshoot**,不引入 scroll-snap。
- S0 与 S1 看到图片的**同一切片**(冻结);两态差异 = 卡片/羽化在场与否 +
  身份组位置与发光。

## 层级结构

```text
body(画布色背景)
├── 导航 / 常规内容层
│   └── .home-flow
│       ├── hero(透明背景,高度 H,身份组 sticky 容器)
│       │   └── 壁纸层(absolute,高 100svh;滚动补偿冻结;仅首页渲染)
│       ├── 统计行(z:11,sticky bottom:12px)
│       └── .home-body(羽化幕布,全宽,z:10)
│           └── 卡片(z:10,上间距 24px)
└── 页脚(显式画布色背景,兜底)
```

scrim = 顶部导航保护 + 文字区压暗(强度沿用构建期亮度采样);
**底部画布羽化不在图片层**(羽化职责在幕布)。

## 几何公式(vh = 100svh)

- `M` = 卡片重叠量 = `clamp(48px, 6vw, 96px)`(移动端 28px)
- `statsH` = 统计行高(单行 mono ≈ 23px;换行时以测量为准)
- `G` = 统计行与卡片间距 = 24px(卡片上间距)
- **hero 高 `H = vh + M − statsH − G`** —— 锁底脚本实测卡片顶位置后一次性调整,
  不依赖各分项估值
- 卡片顶缘文档位置 `C = H + statsH − M + G = vh` —— **恒等于一屏**,
  故 scrollY=0 时卡片顶恰齐视口底缘(S1 停止位由构造保证)
- **行程 `L = d'`**(卡片顶缘 → 简介线底缘,内容相关,JS 测量)
- 锁底:简介线文档位置 = `C + d' = vh + L`;进入偏移 scrollY=L 后横线位于视口底 ✓
- **壁纸层**:高 100svh;冻结位移 `translateY(clamp(scrollY, 0, L))` ——
  行程内钉住视口(满屏不动),行程外随文档滚动。L 由锁底脚本写入
  `--journey` CSS 变量,壁纸层脚本读取
- 身份组:S0 可见区光学中心由实测反推 `padTop = L − M + statsH − 40`;
  sticky 钳制 `bottom: calc(50svh − 组高/2)`,组高由 JS 测量写入 `--gh`
- 发光进度 `p = clamp((s* − scrollY) / s*, 0, 1)`,`s*` = 钳制生效时的 scrollY
  (= 组心自然文档位置 − 50svh,桌面实测约 79~110px)

## 组件规格

### 壁纸层(hero 内 absolute + 滚动补偿冻结)

- `position: absolute; top/left/right: 0; height: 100svh`;`img { 100% cover }`
- **永远恰好一屏大小** → 图片按视口比例缩放,彻底消除 v1 的 1.29 倍放大问题
- 冻结:滚动监听(rAF 节流,与发光同一回调)按 `clamp(scrollY, 0, L)` 补偿位移;
  L 读 `--journey`(锁底脚本设置;未锁底/移动端为 0,即不冻结、纯随动)
- 图上文字色系统不变(`data-img-mode` + 亮度采样 + 深色主题收暗)
- `img-reveal` 淡入机制不变;无图时不渲染本层,回退主题画布,全部构图仍成立
- view-transition 名沿用 `stageMediaName`;跨页转场不串页列入验证清单

### 羽化幕布(.home-body)

- 全宽,`background: linear-gradient(to bottom, transparent, var(--color-canvas) 200px)`
- 卡片经上间距落入羽化段,保持"卡片从图里浮出"的层次
- 幕布底接页脚;页脚显式 `background: var(--color-canvas)`(兜底,无视觉变化)

### 身份组(sticky + 发光)

- 钳制语义:`position: sticky; bottom: calc(50svh − var(--gh)/2)`
  —— 只钳"下移过中",下滚阅读时自由离场
- 发光:钉住段内 `p: 0→1`,标题颜色向主题色混合提亮 + accent 色 text-shadow 光晕,
  由 rAF 节流 scroll 监听驱动;`--glow` 注册为可过渡自定义属性(@property),
  CSS transition 做时间平滑
- 锁底脚本重排身份组后广播 `hero:locked` 事件,发光编排据此重测钳制点
- `prefers-reduced-motion`:无发光、无打字机;sticky 与壁纸冻结保留(纯位置行为)
- 打字机(tagline/intro/统计行)机制不变;光标基础样式在 global.css(跨组件共用)

### 统计行

- 去胶囊:无背景、无圆角、无内边距,纯 mono 小字
- 与卡片顶保持 24px 呼吸距离(卡片上间距承担,锁底自动吸收)
- 永远压在壁纸上(S0 位于 hero 底缘图上区;贴底态压壁纸) → 文字色走图上文字色
  (`--hero-fg-m` 体系,随 img-mode/主题切换),`.home-flow` 上挂载同一 `data-img-mode`
- 三态 sticky 语义不变:`position: sticky; bottom: 12px; z-index: 11`;
  S1 贴底时底边距视口底 24px(与卡片间距同节律)

### 进入偏移

- 硬加载且 `navigation.type === 'navigate'`:锁底计算后 `scrollTo(L, instant)`
- reload / 浏览器返回:交给滚动恢复,不干预
- 软导航前进到首页:同 navigate;`data-nav-dir="back"` 不干预

## 降级与边界

- 内容高于视口(锁底不可达):放弃内联高度,自然流,全部组件仍成立
  (此时 `--journey = 0`,壁纸层不冻结、纯随动)
- **移动端(≤640px)**:停用锁底与进入偏移,自然流——hero 高 `100svh − 56px`,
  进入即"满屏壁纸 + 身份组居中 + 统计行可见 + 卡片顶缘在视口底探头"
  (探头 = 下方有内容的视觉提示);sticky/发光编排照常,壁纸不冻结。
  窄视口下 nav+身份组+简介块的总高超出一屏,强行锁底会把身份组压到导航之下,
  故移动端放弃锁底
- 窄屏:统计行换行时 statsH 以测量为准;M 移动端 28px
- 移动端 svh 系尺寸天然适配地址栏伸缩
- 无背景图:壁纸层缺失 → 画布色,构图与锁底不受影响
- 极宽视口:cover 水平裁切加剧,可接受

## 验收标准(CDP 几何断言 + 目检)

桌面端(>640px,实测 1440×900 / 1366×768):

1. 锁底:`|divider.bottom − vh| ≤ 1`
2. S1(scrollY=0):`card.top − vh ∈ [−1, 2]`;身份组中心 = 50%vh ± 3px;`--glow = 1`;
   统计行底边 = vh − 24 ± 2
3. S0(scrollY=L):横线锁底 ✓;身份组心在可见区中心 ±40px;统计行无背景;
   统计行与卡片顶间距 24 ± 2
4. **冻结**:scrollY ∈ [0, L] 全程壁纸层视口顶缘恒为 0(±1px);
   阅读区壁纸层随文档上移(`backdrop.top = L − scrollY ± 2`)
5. 上滚全程:身份组中心单调逼近 50%vh 后保持不变(钉住);无 overshoot
6. 转场:首页 ↔ 其他页软导航,快照无错位(截图对比);壁纸层不串页
7. reduced-motion:无发光、无打字机;冻结仍生效(位置行为)

移动端(≤640px,实测 390×844):

8. 进入即自然流:scrollY=0,卡片顶缘在视口底探头(0 < vh − card.top < 120),
   身份组近居中(±60px),统计行可见
9. 下滚阅读:统计行离场,`--glow = 0`

通用:

10. `astro check` + `npm run build` 零错误;双档案(showcase / personal)各验一遍

## 范围外

- 其他页(Archive/Tags/Categories/Links/文章页)的舞台图与结构不动
- 搜索、RSS、Links 页配置等既有功能不动
- 壁纸视差(已明确不要)、scroll-snap(已明确不要)、身份组动态重居中(v1 已否决)
